Screen Element Description

  1. Sources: Selects the approved external source to scan.
  2. Possible themes: Lists possible emerging risk themes. AI reads the approved external source and proposes themes, each with a short summary and its source.
  3. Register audit: Checks whether each theme is already covered in the register. AI compares each theme with registered risks by meaning and flags themes not yet covered.
  4. Trial findings: Viability, source and data needs, limitations and next steps.

Assumption

  • Trial: A trial that produces findings and sample outputs, not an operating feature.
