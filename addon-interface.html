Screen Element Description

  1. Configuration (admin): Dashboard views, default filters and notification timing.
  2. Personalisation (user): Default department, saved filters and dashboard layout.
  3. Chat: Guides the user through a review as a conversation. AI asks questions one at a time, explains terms when asked and prompts for missing details.
  4. Form: Shows the review form being filled in. AI turns each answer into the matching field, and the user accepts or edits it.
  5. KRI list: Define KRIs and upload their results.
  6. Conditional workflow: Extra required fields for high-rated risks.

Assumption

  • Access: Simple user, approver (HOD) and admin roles are in the baseline. The 3 access tiers and 6 reporting views are not included.
  • Chatbot: It fills the same fields as the review form. Ratings still come from fixed rules.
